# Requirements: Priyank Pahwa Portfolio Redesign

**Defined:** 2026-05-07  
**Core Value:** Instantly convince recruiters and engineering managers that Priyank is an elite developer with technical project manager maturity.

---

## v1 Requirements

Requirements for the initial high-fidelity launch of the redesigned portfolio.

### 🎨 Core Design & System
- [ ] **DSGN-01**: The user experiences a sleek dark-mode-first aesthetic with a palette of deep Obsidian black, Slate/Graphite gray, Electric Violet, and Jade Emerald accents.
- [ ] **DSGN-02**: Headings use bold geometric sans-serif fonts (`Outfit` or `Sora`), while body copy uses crisp, high-legibility sans-serif (`Inter`).
- [ ] **DSGN-03**: Interactive cards and drawers use smooth glassmorphism layers (`backdrop-filter` blur) with subtle glowing gradients.

### 🚀 Hero Section & Identity
- [ ] **HERO-01**: Hero section displays high-authority headlines framing his systems developer and project manager credentials.
- [ ] **HERO-02**: Prominently features minimalist trust logos of Accenture and Infosys directly in the hero.
- [ ] **HERO-03**: Includes an interactive **"Perspective Switcher"** toggle switch.
- [ ] **HERO-04**: Toggling to `[Systems Dev]` shifts copy and highlights Java/Spring Boot code snippets, database optimization, and cloud configurations.
- [ ] **HERO-05**: Toggling to `[Project Lead]` shifts copy to highlight requirements, user stories, UAT metrics, and stakeholder presentation milestones.

### 🏢 Infosys Experience & StreamFlix Case Study
- [ ] **EXP-01**: Displays the Infosys Winternship not as simple bullets, but as a massive, interactive "Enterprise Case Study" for the **StreamFlix Subscription Engine**.
- [ ] **EXP-02**: Lists deep systems metrics within the case study: Spring Boot 3.4.5, Java 21, React 19, minor units math (paise/cents), and cron billing automation.
- [ ] **EXP-03**: Shares the Technical PM presentation success story, highlighting how he carried the team presentation and answered all technical code queries end-to-end.
- [ ] **EXP-04**: Features an expandable **"Interactive Schema Explorer"** button that reveals a beautifully styled visual diagram of his 23-table relational database model.
- [ ] **EXP-05**: Details his role in enforcing **User Acceptance Testing (UAT) standards** and technical documentation within Infosys agile sprint pipelines.

### 📁 Independent Engineering Projects
- [ ] **PROJ-01**: Displays **Seriva** (AI Wellness Companion) as a standalone project card, highlighting WebGL/Three.js 3D avatar mechanics, OpenAI streaming, and GCP Secret Manager.
- [ ] **PROJ-02**: Displays **PharmaFleet** (Smart Medicine Inventory) as a standalone card, highlighting central audit trails, dashboard analytics, and workflow digitization.
- [ ] **PROJ-03**: PharmaFleet features details on his PM contributions: translating operational workflows into database schemas to achieve a **70%+ error reduction**.
- [ ] **PROJ-04**: Outdated projects (such as "arete") are completely removed from the project listing to keep portfolio quality extremely high.

### 📊 Skills & Career Path
- [ ] **SKILL-01**: Displays a **Skills Bento Grid** divided cleanly into two columns: *Technical Systems Engineering* (Java, C++, TS, React, SQL, GCP) and *Technical Project Delivery* (Roadmapping, Agile/Scrum, requirements, scope, feature prioritization).
- [ ] **SKILL-02**: Features a dedicated tools section showing JIRA, Git/GitHub, Postman, and DB tools.
- [ ] **HORIZ-01**: Features a forward-looking card framing his upcoming Accenture ASE role as a strategic step to master enterprise delivery pipelines on his pathway to PM leadership.

### 📬 Conversational CTA
- [ ] **CTA-01**: Features a sleek, conversational contact form with direct hooks for both Recruiters and Engineering Managers.
- [ ] **CTA-02**: Provides a clear, high-contrast, glowing action button to download his project management/developer resume PDF.
